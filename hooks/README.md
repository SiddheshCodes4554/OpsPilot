# Global Hooks Directory

This directory contains reusable, global custom React hooks for the **OpsPilot AI** application.

## Guidelines
- Hooks here must be generic and applicable across multiple features (e.g., `useDebounce`, `useLocalStorage`, `useMediaQuery`).
- Feature-specific hooks should reside in their respective feature directories (e.g., `features/[feature-name]/hooks/`) rather than here.
